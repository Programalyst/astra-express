# Martian ground

The active surface is `NuclearKnights/Grid Desert.mat`, imported from the
owner's other project. See `NuclearKnights/README.md` for its dependencies, UV
adaptation, and provenance.

Adjust Grid Desert's color and texture properties directly, or assign another
material to Astra Express's Terrain Surface Material to override the default.
Terrain Texture Repeat controls world units per UV repetition
(initially 6). Generated UVs continue across neighboring flat cells and plateaus.
Kenney cliff and ramp meshes are retained; their textures are unchanged.
